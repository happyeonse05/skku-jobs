# skku-jobs — 담다 데이터 크롤러

담다 앱의 **마감함(채용·모집 공지)** 와 **봉룡학사 식단**을 매일 자동으로 가져오는 저장소입니다.

- `data/jobs.json` — 성균관대 채용·모집 공지
- `data/meals.json` — 봉룡학사 식단
- 매일 오전 6시·11시(KST)에 자동 실행되고, Actions 탭에서 수동 실행도 가능합니다.

## 주소가 바뀌었을 때
- 공지 게시판: `crawler/jobs.py` 맨 위 `BOARDS`
- 식단 페이지: `crawler/meals.py` 맨 위 `MENU_URL` / `BOARD_NO`

## 공지 파일 보존

공지 게시판 중 하나라도 요청/파싱 오류 또는 0건이면 전체 공지 갱신을 중단하고 기존 `jobs.json`의 내용과 시각을 그대로 유지합니다. 신규 설치에서도 불완전한 빈 파일을 발행하지 않습니다. 종료 코드는 1이므로 기존 자동화의 commit 단계도 진행되지 않습니다. 정상적인 빈 게시판도 보수적으로 미완료로 간주하므로 운영자가 원문/선택자를 확인해야 합니다.

현재 `update.yml`은 공지 다음에 식단을 실행하므로 공지 실패 시 그 회차 식단 수집도 실행되지 않습니다. 두 작업의 독립 실행/발행은 별도 개선 대상입니다.

모든 게시판에 공지가 있을 때만 기존 형식과 60건 제한을 유지하여 저장합니다. 같은 디렉터리의 임시 파일에 UTF-8 JSON을 쓰고 flush/fsync 후 닫은 뒤 `os.replace`로 교체합니다. 쓰기 실패 시 기존 파일을 보존하고 임시 파일을 정리합니다. 이 처리는 백업이나 다중 프로세스 잠금, 전원 장애 후 디렉터리 내구성을 보장하는 기능이 아닙니다.

검증: `python -m pip install requests==2.34.2 beautifulsoup4==4.15.0 lxml==6.1.3` 후 `python -m unittest discover -s tests -v`. 시험은 임시 경로와 합성 HTTP 응답만 쓰며 실제 공지 수집·기존 `data/` 수정·운영 배포를 하지 않습니다. CI는 Python3.12/3.13에서 시험/구문 검사를 수행합니다. 식단 크롤러의 부분 실패 정책은 이번 변경에 포함하지 않았습니다.
